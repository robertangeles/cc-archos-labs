## lessons-learned
- [Writing site_setting.value with JSON.stringify(obj)::jsonb double-encodes it](lessons-learned/2026-07-19-site-setting-jsonb-double-encoding.md) — `JSON.stringify(x)::jsonb` stored a jsonb *string* wrapping the object, so `getChatPrompt` silently fell back to the placeholder prompt (Metis lost its persona; recall still worked so it hid). Rule: write jsonb objects with `sql.json()` / Drizzle values, never `JSON.stringify(x)::jsonb`; read with a `typeof==="string"` → `JSON.parse` guard.
- ["Crawled – currently not indexed" is mostly domain trust, but hygiene bugs feed it](lessons-learned/2026-07-12-seo-crawl-not-indexed-hygiene.md) — GSC's "crawled not indexed" on a young domain is Google's discretion (fix = backlinks + index requests + content depth), but a 3-agent audit found real feeders: soft-404 out-of-range pagination (200+empty), doubled brand in `<title>` (layout template + `effectiveTitle` both append), `force-dynamic` on indexable routes (cold DB per crawl), bare `JSON.stringify` on layout JSON-LD (`</script>` breakout), Article JSON-LD emitting soft-deleted image URLs, RSS CDATA double-escaping `&`, and `/search` inheriting the homepage canonical. Rules: bounded routes 404 out-of-range; titles are brand-free; indexable = ISR not force-dynamic; JSON-LD via `jsonLdScript()`; client pages need a sibling layout for their canonical.
- [Optimistic upload to a just-created conversation loses the file to two client-side races](lessons-learned/2026-07-07-attach-fresh-conversation-races.md) — attaching to a *fresh* Metis conversation silently uploaded nothing / the chip vanished mid-upload (latent since PR1; only the PR2 E2E caught it). Race 1: reading the live `input.files` FileList after `await newChat()` — the input's `onChange` clears `value=""` and empties it. Race 2: the just-created conversation's empty attachments-load raced + clobbered the optimistic chip. Fixes: snapshot `Array.from(files)` before any await; consume-once `skipAttachLoadRef`. Rule: snapshot live DOM collections before the first await; the cold/first-time path needs its own E2E.
- [LinkedIn API version header sunsets on a ~12-month clock](lessons-learned/2026-07-01-linkedin-api-version-sunset.md) — hardcoded `LINKEDIN_API_VERSION = "202402"` aged out; PROD scheduled LinkedIn posts failed with `426 NONEXISTENT_VERSION` behind the generic "LinkedIn API returned no response". Fix: `process.env.LINKEDIN_API_VERSION ?? "202606"` (env-overridable, current default). Rule: pin provider API version dates to an env var + read the server log (`[social/linkedin] publish <status>`) before trusting the UI string.
- [Next Link to the current URL is a no-op — stateful tools get stuck](lessons-learned/2026-06-29-nav-link-to-current-url-noop.md) — clicking a Tools nav link while already on that page did nothing; Next.js treats a `<Link>` to the current URL as a no-op so a `useState`-driven tool never re-mounts. Fix: in `components/layout/nav.tsx`, intercept the click on Tools links with `href === usePathname()` and force `window.location.href` reload. Rule: if a nav link can point at the current page and that page holds meaningful client state, either force a hard reload or encode state in the URL.
- [Brain recall silently failed on GBrain cold starts — "Metis doesn't remember me"](lessons-learned/2026-06-22-brain-recall-cold-start-timeout.md) — recall's two 5s timeouts (token + vector query) blew the budget whenever GBrain cold-started (same query: ~1.5s warm, >5s cold), and the failure was swallowed → zero memories → generic answers. Data was fine. Fix: widen timeouts (query 10s, token 8s), warm GBrain on workspace open via `warmBrain()` + `POST /api/brain/warm`, and log recall failures in prod. Verified: warm absorbed a 6.2s cold start, recall then returned 5 memories in ~1.8s.
- [A full-bleed canvas needs a definite height — h-full collapses under min-h-full](lessons-learned/2026-06-17-react-flow-height-collapse.md) — the Model Studio React Flow canvas rendered as a zero-height void (build + unit tests clean); only the E2E caught it. Fix: `flex-1 min-h-0` chain + `relative`/`absolute inset-0` leaf. Also documents the no-backdoor Playwright auth-via-register pattern + the in-memory register rate limit.
- [Clean build + passing tests can still 500 — the migration was never applied](lessons-learned/2026-06-16-migration-generated-not-applied.md) — `/workspace/model-studio` 500'd because `data_model` was in schema + migration file + journal, with passing tests and a clean build, but `pnpm db:migrate` was never run so the table didn't exist in the live shared DB. Rule: a clean build that 500s → check `to_regclass`, not the journal; tests and build never touch the live DB.
- [GBrain security hardening — debug endpoints, PII, and schema validation](lessons-learned/2026-06-10-gbrain-security-hardening.md) — debug endpoint shipped to prod (deleted), Zod refine on read-path schema would crash config loader (moved to point-of-use), conversations stored verbatim in external service (PII redaction added). Three rules: no debug in prod, validate at write/use not read, sanitize at the boundary.
